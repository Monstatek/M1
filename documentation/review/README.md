# M1 Engineering Review

This directory contains public, sanitized engineering-review material.

## Structure

- `baselines/` — validated build and test baselines
- `evidence/` — non-sensitive manifests and test evidence
- `findings/` — sanitized bug and risk register
- `security/` — responsible-disclosure guidance

Sensitive or undisclosed material must remain in the ignored
`review-private/` directory at the repository root.
