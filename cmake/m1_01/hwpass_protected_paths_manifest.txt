# hwpass_protected_paths_manifest.txt
#
# Machine-checkable inventory of production paths covered by a hardware-
# accepted checkpoint. Consumed by cmake/m1_01/verify_hwpass_protected_paths.sh
# (POST_BUILD). Maintained by hand; changing ACCEPTED_CHECKPOINT or the
# PROTECTED/FORBIDDEN_SRC set is a deliberate architectural act that MUST
# accompany a new tracked hardware-acceptance record under
# documentation/hardware-acceptance/ and a new annotated checkpoint/* tag.
# There is no other sanctioned way to move this file's baseline.
#
# Sections:
#   ACCEPTED_CHECKPOINT <ref>        -- the single git ref (tag or commit)
#                                        every PROTECTED path is diffed
#                                        against. Must resolve in this repo.
#   PROTECTED <SUBSYS> <path>        -- a production file or directory that
#                                        must be byte-identical to its content
#                                        at ACCEPTED_CHECKPOINT. <path> may be
#                                        a directory; test/ subdirectories are
#                                        never listed, so a diff here is always
#                                        a production change, never test-only.
#   FORBIDDEN_SYM <SUBSYS> <symbol>  -- must NOT be a defined text symbol in
#                                        the linked ELF (checked only when the
#                                        guard is run POST_BUILD with an nm
#                                        tool + ELF path; a bare source-text
#                                        mention -- e.g. a comment containing the
#                                        symbol name -- is deliberately
#                                        NOT a match, matching the reasoning
#                                        in verify_hwpass_protected_paths.sh).
#
# Subsystem tags: MFC, LFRFID, SUBGHZ, STORAGE, LED, WIFI_UI, BUILD, SHARED.
# SHARED = a single file that is a load-bearing dependency of more than one
# hardware-accepted subsystem (e.g. shared MSP timer/GPIO init); a diff there
# invalidates every subsystem listed in its comment, not just one.
# BUILD = compilation-membership / guard wiring for the accepted subsystems.
