# mfc_authoritative_manifest.txt
#
# Machine-checkable inventory of the ONE authoritative MIFARE Classic (MFC)
# implementation. Consumed by cmake/m1_01/verify_mfc_arch.sh (POST_BUILD) and
# by the host forbid-test. Maintained by hand; changing it is a deliberate
# architectural act.
#
# Sections:
#   REQUIRED_SYM  -- must be a defined text symbol in the linked ELF (the live
#                    Flow-A RAWOWN/Crypto1/DMA/session/HAL backend).
#   FORBIDDEN_SYM -- must NOT be a defined text symbol (obsolete generic-MFC or
#                    the deleted duplicate Flow-B listener-frame crypto backend).
#   FORBIDDEN_SRC -- a regex that must NOT match any active (non-comment) line
#                    of the production source tree (obsolete routes/flows).
#   FORBIDDEN_CMAKE -- a regex that must NOT match active CMake configuration
#                    (a build option selecting an alternate/legacy MFC backend).
#
# Live emulate path (Flow A): nfc_driver.c -> m1_mfc_raw_hw_run (session_hw)
#   -> m1_mfc_session take_auth/on_nrar/on_read -> ce_mfc + crypto1, TX via
#   m1_mfc_dma_tx_frame, RAWOWN HAL direct. Live read: nfc_poller ReadCycle ->
#   m1_mfc_read_card -> dictionary/key-source machinery.
