M1CP Web Serial Test Client

Engineering validation tool for M1CP v1 (Gate A/B/C) — not the final web app.
Read-only client: FW_APPLY, FW_ACTIVATE, bank/flash operations and ESP32 flashing are hard-blocked (opcodes 0x21–0x3F). Only Gate A queries, Gate B Add Files, and the read-only FW_VALIDATE (0x20) can be sent.
This browser has no Web Serial API. Use Chrome/Edge (desktop) over HTTPS or http://localhost.
